# Roblox-Blender-Fov
Plugin that allows you to easily import animation of cameras Field of View from blender to roblox
## Usage
* Select the camera in the plugin's Panel
* incase of camera compatibility issues popping up, press FIX CAMERA to fix all the issues with the camera
* Press copy to clipboard
* Go to roblox studio and press Convert FOV and paste the copied code
* if you had moon file selected, it will automatically paste the new converted FOV keyframes in there, if not then the FieldOfView folder will be placed in the workspace
